# Security policy

Do not attach disk images, recovered files, filenames, or personal metadata to public
issues. Report security vulnerabilities privately through GitHub's security advisory flow
for this repository. This tool intentionally has no network or telemetry behavior.

No version is considered production-stable before the first reviewed release. Security
reports should include a synthetic reproduction whenever possible. Source-write,
overwrite, path-traversal, parser resource-exhaustion, and manifest-integrity issues are
treated as security-relevant.
